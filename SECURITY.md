# Security policy

## Supported versions

Only the latest MuSicX 15 release receives security fixes.

## Reporting a vulnerability

Do not report security vulnerabilities in public issues.

Use GitHub Security Advisories at https://github.com/ufoptg/MuSicX/security/advisories/new with a description of the issue, the affected version and steps to reproduce it. We will acknowledge your report and update you as we work on a fix.

## Build security

Build only from tagged releases or CI artifacts. Do not commit secrets, keystores or signing keys.
